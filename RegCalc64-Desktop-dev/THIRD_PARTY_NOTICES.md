# Third-Party Notices

## Microsoft Edge WebView2

RegCalc64 Desktop uses the Microsoft Edge WebView2 SDK/Runtime to host the local HTML/CSS/JavaScript UI in a native Win32 application.

The WebView2 SDK is downloaded at build time from the official `Microsoft.Web.WebView2` NuGet package. The official Microsoft Evergreen Bootstrapper is also downloaded at build time and embedded in the final EXE so users can install the Runtime after explicit confirmation when it is missing.

See Microsoft's WebView2 license and distribution documentation for applicable terms.
