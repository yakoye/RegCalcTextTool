# Image Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增独立 Image 标签页，在浏览器本地完成图片输入、预览、格式转换、压缩、缩放、旋转翻转、BMP/ICO 生成和下载。

**Tech Stack:** 原生 HTML/CSS/JavaScript、Canvas 2D、Blob、Object URL、File API、Node `node:test`。

### Task 3: 实现图片变换和输出

**Files:**
- Modify: `image-tool.js`

- [ ] **Step 1: 实现尺寸计算**

```js
function calculateOutputSize(sourceWidth, sourceHeight, requestedWidth, requestedHeight, keepRatio) {
  if (!keepRatio) return { width: requestedWidth, height: requestedHeight };
  if (requestedWidth) {
    return { width: requestedWidth, height: Math.round(sourceHeight * requestedWidth / sourceWidth) };
  }
  return { width: Math.round(sourceWidth * requestedHeight / sourceHeight), height: requestedHeight };
}
```

宽高必须是 1 至安全上限的整数，像素总量超过 40,000,000 时拒绝。

- [ ] **Step 2: 实现 Canvas 变换**

按以下顺序：

```text
计算目标尺寸
设置旋转后的画布尺寸
填充背景色
移动到画布中心
应用旋转
应用水平或垂直翻转
绘制源图
编码输出
```

JPEG 输出始终填充用户选择的背景色；PNG、WebP 和 BMP 默认保留透明度。

- [ ] **Step 3: 实现格式输出**

```js
async function canvasToOutput(canvas, format, quality) {
  if (format === "image/bmp") {
    const data = canvas.getContext("2d").getImageData(0, 0, canvas.width, canvas.height);
    return ImageCodecs.bytesToBlob(
      ImageCodecs.encodeBmp({ width: canvas.width, height: canvas.height, rgba: data.data }),
      "image/bmp"
    );
  }
  return new Promise((resolve, reject) => {
    canvas.toBlob(blob => blob ? resolve(blob) : reject(new Error("浏览器不支持该输出格式")), format, quality);
  });
}
```

检测请求 WebP 却返回 PNG 的浏览器回退并显示“不支持 WebP 输出”。

- [ ] **Step 4: 实现多尺寸 ICO**

对 16、32、48、64、128、256 尺寸分别绘制 PNG Blob，转为 `Uint8Array` 后调用 `ImageCodecs.encodeIco`，输出 `image/x-icon`。

- [ ] **Step 5: 实现结果和下载**

显示输出格式、宽高、大小和：

```js
const savingPercent = sourceSize
  ? ((sourceSize - outputSize) / sourceSize * 100).toFixed(1)
  : "0.0";
```

结果变大时显示“增加 N%”，不显示为压缩成功。下载名沿用原文件名并替换扩展名。

- [ ] **Step 6: 保存非敏感偏好**

键 `toolbox.image.settings.v1`：

```js

  format: "image/webp",
  quality: 85,
  keepAspectRatio: true,
  backgroundColor: "#ffffff",
  icoSizes: [16, 32, 48, 64, 128, 256]
}
```

不得保存图片、文件名、Object URL 或剪贴板内容。
